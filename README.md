# WAUG 2026 Sports Data Analysis

## Overview
An ongoing sports data analysis project focused on the
West African University Games (WAUG) 2026.

## Objectives
- Analyse participation and medal performance across sports.
- Investigate football performance and match statistics.
- Clean and validate collected data.
- Develop visualisations and a Power BI dashboard.

## Tools
- Excel
- Python
- Power BI
- Git and GitHub
